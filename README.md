## Features

### 🎨 Multi Accent System

Instead of using one color across the entire profile, every major section has its own palette.

| Section | Accent |
|---------|--------|
| Anime | Cyan → Indigo |
| Manga | Crimson → Gold |
| Favorites | Violet → Pink |

This makes every page feel unique while keeping the same overall identity.

---

### 🌌 Modern Glassmorphism

The theme includes:

- Frosted glass cards
- Soft shadows
- Blurred panels
- Rounded components
- Dark gradients
- Ambient overlays

without sacrificing readability.

---

### 🖼 Completely Customizable

Simply replace the image variables at the top of the CSS.

```css
--banner-url:
--avatar-url:
--search-gif:
```

No other edits are required.

## Customization

### Colors

All colors are stored inside `:root`.

Example:

```css
--accent-anime-start:
--accent-anime-end:

--accent-manga-start:
--accent-manga-end:

--accent-fav-start:
--accent-fav-end:
```

You can completely change the theme by editing these values.

---

### Images

Replace these:

```css
--banner-url
--avatar-url
--search-gif
```

with your own links.

Supported hosts include:

- Catbox
- Imgur
- GitHub
- Discord CDN
- Any direct image URL

## Installation

### Step 1

Open your AniList settings.

### Step 2

Navigate to:

```
Settings
→ Profile
→ About
→ Custom CSS
```

### Step 3

Paste the contents of `theme.css`.

Save.

Done.
